LinkedIn UI Recreation
A front-end recreation of the LinkedIn interface, developed
to practice and improve HTML5 and CSS3 skills.

Overview
This project consists of recreating the visual layout of
LinkedIn, focusing on page structure, styling, alignment,
spacing, and component organization.

Technologies
- HTML5
- CSS3

How to Execute
Open the link: "https://guhsites.github.io/linkedin-page/" in your browser.

Project Status
In progress as a front-end learning project.
